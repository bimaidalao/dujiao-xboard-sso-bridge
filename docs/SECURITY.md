# 安全说明

## 强制要求

- 两个公开站点必须使用 HTTPS。
- 密码哈希接口只绑定 `127.0.0.1` 或受控 Docker/私网，并按 `BRIDGE_TRUSTED_CLIENTS` 校验来源。
- 不要提交 `.env`、数据库、JWT 密钥、日志、备份或 SSH 私钥。
- 自动创建账号前，必须验证邮箱格式、邮箱验证状态和账号状态。
- redirect 必须使用固定白名单，禁止接收完整外部 URL。
- SSO 响应必须设置 `Cache-Control: no-store`、`Referrer-Policy: no-referrer` 和严格 CSP。
- 对公开 SSO 路径设置请求体上限和速率限制。

## 密码共享

密码共享只复制 bcrypt 哈希，不获取明文密码。开始同步前必须确认两边哈希格式都受目标验证器支持。

- 凭据接口不得被 Nginx 暴露到公网；
- 返回哈希前必须重新校验当前登录 Token；
- 日志中不得记录 Token、Authorization 头或密码哈希；
- 密码发生变化时，应增加目标账号的 token version 或清理旧会话；
- 不兼容的哈希格式必须拒绝同步。

## 数据最小化

账号桥接只处理邮箱、账号状态、用户 ID、token version 和兼容密码哈希。工单功能额外读取当前用户在两个系统各自最近一笔订单的订单号、商品/套餐、金额、状态和时间。

严禁进入工单摘要的数据包括：

- 卡密、账号密码和自动发货正文；
- 支付回调原文、支付凭据和完整账单信息；
- 管理员字段、其他用户订单和内部密钥。

AI 商店订单必须用当前 Xboard Authorization 重新校验，并按映射邮箱查询；节点订单必须按当前 Xboard `user_id` 查询。不能信任浏览器传入的用户 ID 或任意订单号。

## Docker 网络

- host 网络继续使用 `127.0.0.1`；
- bridge 网络只信任安装器检测到的 Docker 子网；
- `18081/tcp` 必须在云防火墙或主机防火墙禁止公网访问；
- 不允许为了省事使用 `0.0.0.0/0` 作为可信来源。

## 升级风险

Dujiao Next 或 Xboard 升级后，用户表字段、JWT claims、登录服务或路由可能变化。必须先在测试环境运行双向登录和密码校验，再更新生产环境。
