# 安全说明

## 必须遵守

- 两个公开站点必须使用 HTTPS。
- 内部用户信息接口只绑定到 `127.0.0.1` 或受控私有网络。
- 不要把 `.env`、数据库、应用配置、JWT 密钥或日志提交到 Git。
- SSO 创建账号前必须验证来源账号的邮箱已验证且状态正常。
- 跳转地址必须使用固定白名单，禁止直接接受完整 URL。
- SSO 响应设置 `Cache-Control: no-store` 和严格 CSP。
- Web 服务器应限制请求体大小，并对 SSO 路由限流。

## 数据最小化

身份桥接只需要邮箱和账号状态。不要返回密码哈希、支付记录、卡密、订单交付内容或管理员字段。

## 已知限制

示例中的反向桥接通过 Dujiao Next 的 SQLite 数据库创建用户并签发其原生 JWT。升级上游程序后，应先在测试环境核对数据库字段与 JWT claims。
