# AI 商店订单关联工单

本项目扩展 Xboard 原有工单，不创建第二套工单系统。用户提交工单时无需选择订单，服务端会自动附带两个系统各自最近一笔订单。

## 用户看到的内容

- 跨境速运节点套餐、流量、到期时间等原有工单信息保持不变；
- 用户无需选择或判断订单归属；
- 创建工单时自动附带跨境速云与 AI 工具商店各自最近一笔订单；
- 某一系统没有订单时只附带另一系统已有的订单；
- 工单自动附带订单号、商品、金额、中文状态和下单时间；
- 用户同时拥有两边业务时，同一工单会同时保留“节点账户/套餐信息”和“关联 AI 工具商店订单”，标题明确区分来源；
- 不读取、不传输卡密、自动发货正文或其他交付秘密。

## 安全校验

Xboard 节点订单直接按当前登录用户查询。AI 商店订单由 Xboard 服务端把当前 Authorization 会话交给本地桥接服务重新验证，桥接服务再按同一邮箱查询 Dujiao SQLite 数据库。两边都只读取当前用户最近一笔订单，不能通过修改浏览器请求关联他人的订单。

`/sso/orders` 只允许 `XBOARD_PUBLIC_ORIGINS` 中列出的来源跨域访问，并始终返回 `Cache-Control: no-store`。

## 手机端行为

在小屏幕设备上：

- 工单弹窗最大高度限制在可视区域内，内容可以上下滑动；
- 工单页面隐藏 AI 商店悬浮卡片，避免遮挡提交或回复；
- 输入框获得焦点、系统键盘弹出时，底部导航临时收起；
- 退出输入或关闭工单窗口后恢复原有导航。

## 兼容性

安装器会备份并修改 Xboard V1 用户路由，将 `/user/ticket/save` 指向 `StoreOrderTicketController`，同时运行数据库迁移，为 `v2_ticket` 增加 `go_order_id` 和 `go_order_no`。升级 Xboard 后应执行 `bin/dx-bridge check` 并验证路由和迁移状态。
