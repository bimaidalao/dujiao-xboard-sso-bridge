# 二开功能说明

## 1. 双向单点登录

商城和节点面板都保留自己的会话系统。桥接层只在用户主动点击跨站入口时验证来源会话、查找同邮箱账号并签发目标站会话。

## 2. 自动账号创建

目标站没有同邮箱账号时自动创建。自动创建账号必须满足：来源邮箱已验证、账号未禁用、邮箱格式有效。已有同邮箱账号不会重复创建。

## 3. 密码共享与独立登录

两边使用兼容 bcrypt 时，SSO 会把来源站的哈希同步到目标站。因此账号关联后既可以一键登录，也可以在任一站使用同一邮箱和密码独立登录。

旧账号存在不同密码时，以最近一次发起 SSO 的来源站密码为准。因为密码不可逆，无法在不选择来源的情况下自动判断两个旧密码哪个应保留。

## 4. 跨站入口组件

- 支持站点 Logo、标题和副标题；
- 支持日间/夜间主题；
- 桌面端悬浮，手机端紧凑布局；
- 容器使用 `pointer-events: none`，只有真实按钮接收点击，避免隐形遮罩；
- 可放置在底部导航上方，并避开“回到顶部”按钮。

## 5. 手机端客服

工单客服和 Telegram 客服可折叠到底部导航的“客服”菜单。展开层只覆盖自身区域，关闭状态为 `display: none`，不阻止页面滑动。

## 6. 注册入口强化

登录页原有灰色注册链接可增强为高对比渐变按钮，增加“新用户入口”角标，并兼容日夜主题和手机宽度。

## 7. 尚未包含

- 商城订单自动附加到 Xboard 工单；
- 两个系统订单数据互相写入；
- 支付、卡密或自动发货数据同步；
- 多服务器分布式凭据服务。

这些功能应通过独立、最小权限 API 实现，不应直接暴露数据库或复用管理员接口。
